# Ligand parameterisation artefacts

Two pipelines, two parameter formats:

| File | Generated by | Used by |
|---|---|---|
| `GH6.sdf` | `molgent.core.ligand.smiles_to_sdf` (RDKit ETKDGv3) | OpenMM/AMBER reference (`molgent-clc2`) |
| `GH6_from_pdb.{pdb,sdf,mol2}` | `molgent.core.ligand.extract_from_pdb` from `data/structures/8gqu.pdb` | both pipelines (preserves CCD atom names ``N08`` / ``O01`` / ``O03`` ...) |
| `GH6.xml` | `openmmforcefields` GAFF generator (run once on a conda host) | OpenMM/AMBER reference |
| `gh6.str` | https://cgenff.silcsbio.com/ (upload `GH6_from_pdb.mol2`) | GROMACS/CHARMM36m (`molgent-clc2-gmx`) |

## Regenerating the extracted CCD pose

```bash
python -c "
from pathlib import Path
from molgent.core.ligand import extract_from_pdb
extract_from_pdb(
    pdb_path=Path('data/structures/8gqu.pdb'),
    resname='GH6', chain='A',
    smiles='OC(=O)c1cccnc1Nc2c(Cl)ccc(OCc3ccccc3)c2Cl',
    out_dir=Path('data/ligands'),
    name='GH6',
)"
```

The extracted PDB keeps the cryo-EM bound pose so the paper's diagnostic
distances (K204(NZ)–N08, S392(OG)–O01, K394(N)–O03) start in the correct
geometry. RDKit-generated conformers from SMILES alone do **not** preserve
the bound pose and shouldn't be used for the GROMACS pipeline.

## Generating CGenFF parameters

1. Open https://cgenff.silcsbio.com/ (free account or licensed binary).
2. Upload `GH6_from_pdb.mol2`.
3. Save the returned stream file as `gh6.str` here.
